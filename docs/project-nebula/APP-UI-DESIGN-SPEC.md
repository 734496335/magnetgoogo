# magnetgoogo App UI 设计规范

文档版本：v0.1
更新时间：2026-04-25
对应资源：`UI/logo.png` / `UI/ChatGPT Image Apr 25, 2026, 09_21_58 AM.png`

## 1. 目标

本规范用于约束 `magnetgoogo` App 首版 UI 的视觉与交互统一性，确保后续继续扩页面时不偏离当前高保真稿。

产品气质：

- 极简
- 高级
- 安静
- 可信
- 轻盈

不允许做成：

- 资源站堆叠风
- 后台系统风
- 强运营广告站风
- 高对比廉价科技风

## 2. 核心页面状态

首版视觉主状态只有两个：

1. 未搜索态
2. 搜索结果态

并且统一放在“手机设备壳”容器中展示，形成强产品感。

## 3. 版式原则

### 3.1 设备壳

- 页面主体采用双设备壳并列布局
- 每个设备壳圆角约 `40px - 48px`
- 外层为半透明白色玻璃容器
- 内层为近白色纯净画布
- 大阴影，但阴影要柔，不要脏

### 3.2 留白

- 首页必须大留白
- 搜索框和品牌必须成为唯一视觉重心
- 结果页卡片间距宽松，不能密集压迫

## 4. Logo 使用规范

- 优先使用 `logo.png`
- 首页使用大尺寸 logo
- 结果页顶部使用缩小版 logo
- 不允许自行改色
- 不允许加描边、投影、黑底胶囊等二次装饰

## 5. 色彩规范

### 5.1 背景

- 整体背景为暖白灰渐变
- 可叠加极淡的径向光晕
- 不使用纯白死板底

推荐背景区间：

- `#f8f7f4`
- `#f6f5f2`
- `#fdfdfd`

### 5.2 文字

- 主文字：`#1f2430` 左右
- 次文字：`#70778a` 左右
- 辅助文字：`#96a0b0` 左右

### 5.3 品牌与按钮

- 品牌主按钮采用多彩渐变
- 渐变必须柔和、发光、清透
- 禁止用高饱和硬渐变或廉价霓虹

推荐渐变方向：

- 蓝 -> 紫 -> 橙 -> 绿

## 6. 首页规范

### 6.1 结构

- 状态栏
- 大 Logo
- 一句短副标题
- 大搜索框
- 大渐变按钮

### 6.2 搜索框

- 高度较大
- 圆角大
- 浅阴影
- 左侧固定搜索图标
- 占位文案为浅灰蓝

### 6.3 主按钮

- 胶囊形
- 强渐变
- 中心对齐
- 文字白色、字号明显
- 箭头作为唯一辅助图形

## 7. 搜索结果页规范

### 7.1 顶部

- 小 Logo
- 单行搜索框
- 清空按钮仅保留轻图标

### 7.2 结果卡片

每张卡片只展示必要信息：

- 资源标题
- 一行基础元信息
- 标签
- 一个主操作按钮 `复制磁力`

禁止展示：

- 源站域名
- 抓取状态
- 技术字段
- 详情页入口

### 7.3 卡片风格

- 大圆角
- 白卡片
- 很轻的边框或 ring
- 柔和阴影
- 左侧有彩色图标底板
- 右侧是标题、元信息、标签、按钮

## 8. 标签规范

标签最多同时展示 `4 - 6` 个。

标签优先级：

1. 清晰度
2. 片源类型
3. 字幕
4. 质量提示

标签必须：

- 圆角胶囊
- 浅底色
- 深色字
- 不允许高饱和纯色块

## 9. 动效规范

- 结果卡片轻微上浮淡入
- 按钮 hover / press 只有很轻的缩放
- 禁止大幅弹跳、旋转、飞入
- 整体动效应短、稳、安静

## 10. 响应式原则

- 桌面端优先展示双设备壳
- 平板端可缩放双设备壳
- 移动端切为单设备壳纵向布局
- 不能因为响应式而破坏整体高级感

## 11. 后续页面扩展要求

后续若新增：

- 收藏页
- 历史页
- 我的页
- 会员页
- 关于页

都必须继承以下视觉共性：

- 同一设备壳系统
- 同一圆角体系
- 同一阴影体系
- 同一浅白灰背景
- 同一文字层级
- 同一标签风格
- 同一主按钮逻辑

## 12. 实现备注

当前实现应严格以高保真图为准，若后续需要新增页面，必须先对齐本文档后再扩展组件。
