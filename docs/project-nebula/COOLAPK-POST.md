## 酷安应用商店上传（如需）

如果要把 APK 上传到酷安应用市场：
1. 打开 https://developer.coolapk.com
2. 注册开发者账号
3. 上传 APK + 应用描述 + 截图
4. 等待审核（通常 1-3 天）

上传后帖子中可以直接"关联应用"，用户可以在酷安内直接下载。
