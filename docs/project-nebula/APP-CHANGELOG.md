## 打包检查清单

打包新版本前确认：
1. [ ] 所有「未打包优化」已测试
2. [ ] `package.json` 版本号已更新
3. [ ] `app.json` / `app.config.js` 的 `versionCode` 已递增
4. [ ] 运行 `eas build --platform android --profile production`
5. [ ] APK 上传至 R2 + 阿里云
6. [ ] `config.json` 的 `latest_version` 已更新
7. [ ] 将「未打包优化」移至「已打包发布」区域
