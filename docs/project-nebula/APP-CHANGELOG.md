### 已纳入功能

- 搜索源调度由“逐个源主机跑完”升级为“按内容池分阶段搜索”：同池镜像只在主机失败或空结果时兜底，达到足够多的全局去重高相关结果后提前结束；App 本地按查询类型学习高相关产出、相关率与耗时，不保存原始关键词。最终 K30S 冷启动回归中，`Inception` 由 79.3 秒降至 6.4 秒、约 120 个 host 降至 14 个；`流浪地球 / 海贼王 / Breaking Bad` 均在 12 个池内于 8.6 / 9.9 / 7.4 秒完成，4 类错误数均为 0。

- 修复跨进程旧快照污染、新旧搜索 token 串扰及 A→B 切换触发前台服务崩溃。
- 数据源启动同步单次化、搜索并发与旧结果覆盖防护、存储与配置异常加固。
- 搜索结果分类、大小解析、排序、动画与多语言错误状态等稳定性修复。
