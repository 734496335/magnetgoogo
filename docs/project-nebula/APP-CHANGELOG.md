## v0.2.1（开发中，未发布）— 2026-07-25

### 当前已纳入

- 后台搜索可靠性修复：极速切后台接管、部分结果持续恢复、终态自动回填与服务清理。
- 修复跨进程旧快照污染、新旧搜索 token 串扰及 A→B 切换触发前台服务崩溃。
- 数据源启动同步单次化、搜索并发与旧结果覆盖防护、存储与配置异常加固。
- 搜索结果分类、大小解析、排序、动画与多语言错误状态等稳定性修复。
- 新增底部“搜索 / 资源 / 设置”三 Tab；原搜索能力与原设置功能分别迁入对应 Tab。
- “资源”模块已移除 JavBus 成人内容，切换为 SixV 最新 50 部影视，包含 9 部红色推荐；列表和详情的资源数量统一按磁力资源统计。
- 资源页重构为极简电影发现体验：顶部只保留“影视”，直接进入横向“值得一看”推荐区和纵向“最近更新”列表，不再展示内容数量与更新时间。
- 电影详情页集中展示剧情、影片信息和导演演员；资源区域只保留磁力卡片，标题统一为“资源”，并复用搜索结果的“复制磁力 / 立即打开”交互。
- 磁力卡片增强边框、阴影、磁力图标、清晰度标签和蓝/橙高对比操作区，不再展示百度、夸克、迅雷和提取码。
- 新增 schema 0005：50 张封面压缩写入 SQLite BLOB，构建时导出本地海报随 APK 打包，国内网络和离线环境均可展示。
- 新增电影 Feed 严格校验、旧成人字段阻断、Android 离线资产注入、标题/类型清洗和 K30S 真机验收证据。

### 发布前剩余

- 完成 v0.2.1 最终发布验收和正式签名构建；当前电影内容仍以构建时离线快照更新。
- 后续可增加安全的影视 Feed/海报增量更新机制，但不作为本轮发布前 blocker。

> 当前仍为 v0.2.1 开发版本：不打 Release、不上传正式 APK、不部署远程配置。
