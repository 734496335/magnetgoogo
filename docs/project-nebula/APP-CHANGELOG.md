### v0.1.11 详细变更

**搜索性能优化：**
- 增量去重：sync 只处理新增结果，不再全量重算（O(new) vs O(total)）
- 分阶段搜索：HTTP 源 15 并发 → WebView 源 4 并发 + 25s 超时
- Context Provider useMemo 优化，防止级联重渲染
- debounce 300ms→500ms

**搜索进度文案（10 种语言）：**
- 搜索中：`搜索 15/115 个源，找到 20 条结果`
- 搜索完成：`已搜索 115/115 个源，找到 189 条结果`

**埋点增强：**
- 新增 `src_empty` 事件：源可达但无结果（之前错误归类为 `src_fail`）
- 区分：`src_ok` / `src_empty` / `src_fail`

**⚠️ 签名变更：**
- 新签名与 v0.1.10 不同，旧版用户需卸载重装
- 原因：keystore 文件丢失后重建（详见 DEV-LOG.md 事故记录）
