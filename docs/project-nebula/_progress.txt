TASK: 搜索资源大小单位误识别修复
STATUS: IMPLEMENTED_AND_K30S_VERIFIED / NOT_YET_IN_FORMAL_APK
DATE: 2026-08-01 UTC+8

ROOT CAUSE:
- SSBC API的size字段是KiB计数，旧代码按bytes格式化，大小缩小约1024倍。
- 真实反例：24672993 KiB被显示24.7MB，正确为23.5GB。
- 同hash合并曾冻结第一个非空大小，后续正确值无法纠正。

FIX:
- 新增统一resourceSize authority，支持IEC/常规/中文/无空格/多大小标签。
- SSBC固定KiB×1024换算。
- 前台、后台和legacy dedup统一保留同hash最大总大小。
- 容器多大小回退选择最大有效值，4K不误识别为4KB。

VERIFICATION:
- K30S搜索“消失的人”：目标hash由24.7MB纠正为23.5GB。
- 3.3MB、2.5MB分别纠正为3.16GB、2.42GB。
- TypeScript PASS；App 53/53；Fluency 17/17；Debug build/install PASS。
- resource/media/cache/security/network/update/release gates PASS；357 rules ALL VALID。
