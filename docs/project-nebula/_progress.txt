## M2-A implemented
- Added backend-neutral `PublisherBackend` plus Cloudflare `R2PublisherBackend` using the S3-compatible API.
- Publication order is immutable objects -> verified Manifest -> isolated staging pointer candidate; production `v1/current.json` cannot be uploaded or promoted.
- Every source file is re-hashed before upload; remote verification checks size, SHA-256 metadata and, by default, a downloaded body hash.
- Immutable creation uses `If-None-Match: *`; same-content races reuse the winner and different-content races block.
- Existing matching objects are reused, interrupted runs resume, and path collisions never overwrite remote data.
- Added bounded exponential retry for 408/429/5xx and transient R2 errors; each retry reopens the local file.
- Added destination locks with active-lock protection, dead-PID recovery and a grace window for newly created PID-less locks.
- Each attempt keeps an independent success/failure `media-publish-receipt/1`; retries do not overwrite prior evidence.
- R2 credentials are accepted only from environment variables; CLI requires `--yes` and an `m2-test*` prefix.
